# Jabartah Trivia — Frontend

Nuxt 4 SPA (Nuxt UI v4, Tailwind v4) for جولة — Arabic-only, RTL, `ssr: false` since this is a shared-screen kiosk app rather than a content site. See the root [`README.md`](../README.md) for the project overview and [`CLAUDE.md`](../CLAUDE.md) for full architecture details.

## Setup

```bash
npm install
npm run dev          # http://localhost:3030
```

Uses **npm**, not pnpm.

The backend API must also be running (see [`../Jabartah.Trivia-backend/README.md`](../Jabartah.Trivia-backend/README.md)) — the frontend derives its API base URL at runtime from whatever host it was itself loaded from, so no manual config is needed for local development.

## Other commands

```bash
npm run build
npm run lint
npm run typecheck
```

## LAN / multi-device play

Password mode's QR-reveal flow needs a second physical device (the clue-giver's phone) to open a link generated by the shared screen. To test this, run the API bound to all interfaces (`dotnet run --urls http://0.0.0.0:5081`) and load the shared screen via the host machine's LAN IP rather than `localhost` — see `CLAUDE.md`'s "LAN/multi-device play" section for how this is wired up.
